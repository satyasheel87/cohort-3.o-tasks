🌐 Browser Rendering Pipeline

How the browser converts your HTML & CSS into what you see on screen.

HTML Side

📄
HTML File
Raw HTML text received from server
↓
🔡
Tokenization
HTML is broken into tokens: start tags, end tags, text, comments
↓
🔍
Parsing
Tokens are parsed into nodes by the HTML parser
↓
🌲
DOM Tree
A tree of Node objects representing the document structure

CSS Side

🎨
CSS File
Stylesheets linked or embedded in the HTML
↓
🔡
Tokenization
CSS text split into tokens: selectors, properties, values
↓
🔍
Parsing
Tokens are parsed into style rules
↓
🎭
CSSOM Tree
CSS Object Model — a tree of style rules applied to elements
DOM Tree + CSSOM Tree
↓
🖼️
Render Tree
Only visible nodes are included. Elements with display: none are excluded. The render tree is used for Layout (calculating positions & sizes) and Painting (drawing pixels on screen).
